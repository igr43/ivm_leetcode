## Как пользоваться

Каждая задача — отдельный раздел ноутбука с заголовком «номер. название» и решением в формате класса `Solution`, который можно скопировать прямо в редактор LeetCode.

```bash
pip install jupyter
jupyter notebook
```

Внешних библиотек не требуется — только стандартная библиотека Python.
